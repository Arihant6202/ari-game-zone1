Free Spark plan status

Gmail login and private profile cloud-save can work on the Firebase Spark plan.

Coin generation/removal, player-to-player transfers, secure bans, and server-side reward validation are disabled.

These actions need a trusted backend. Do not enable public database writes to coins or moderation data to imitate admin controls; players could exploit them.

Current limitations

  • Game coins, XP and levels remain on the player's device; they are not securely synchronized to cloud.
  • Profile name/photo are stored privately under that player's Firebase Auth UID.
  • Phone OTP is subject to Firebase SMS quota, region and billing restrictions.
  • Admin coin controls and UID bans require a trusted backend; this free-only build does not provide them.
