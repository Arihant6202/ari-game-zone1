ARI GAME ZONE — FIREBASE / DEVELOPER SETUP

1) Firebase project
- Keep the Firebase web app configuration in firebase-config.js.
- Enable Google sign-in and Realtime Database.
- Publish database.rules.json to Realtime Database > Rules.

2) Owner account
- Developer Mode is restricted to the verified owner Gmail: kumararihant625@gmail.com.
- The owner Player ID is 97835276.
- Open the website, sign in with that Gmail, then open Developer Mode.
- Do not share the owner Gmail or its sign-in access.

3) Player Mail and Gold Coins
- Developer Mode can send Gold Coins and a text message to one registered 8-digit Player ID.
- The player receives a Mail entry and must claim the Gold Coins in the Mail inbox.
- Message-only Mail is shown as read-only announcement text.
- Developer Mode > Send Mail can target one Player ID or ALL existing players, with message, coins and items.
- Developer Mode > Ban / Unban blocks a Player ID (must have logged in with Google once).
- A player must have opened the game and registered their Player ID at least once to be included.

4) Security notes
- Never publish permissive public read/write rules.
- The owner can read uidIndex and write adminGrants; each player can read their own grant queue and remove only their own delivered grants.
- A player can only read/write their own users/{authUid} data.

5) Deploy
- Upload the complete ZIP contents to the same GitHub Pages repository root.
- If Firebase rules are changed, publish them in Firebase Console as well; uploading the JSON file to GitHub alone does not publish database rules.
